# Vendor Balance Summary

Reports → Vendor → Vendor Balance Summary displays Bangkit Bersama Indonesia, the report title, All Transactions subtitle, vendor balances under a date column, and a grand total. The As of control defaults to today in Asia/Jakarta. Reports remains restricted to superadmin; Sales and Admin 1/2/3 cannot open it.

Uses the same historical bill/credit/payment/write-off projection as A/P Aging Summary. Signed vendor balances include bill PPN and approved supplier return tax reversals through As of. Payments and write-offs reduce AP; PO does not create AP. Negative balances are vendor credit. Zero-net vendors are hidden. The grand total matches A/P Aging Summary for the same date. No screenshot balances or opening AP are imported. Data remains in demo memory and resets on reload.
