# BBI users — session master

Seven active named user records are seeded with stable IDs: Doni, Lutfi and Dipa (Sales); admin 1, admin 2, admin 3 and admin super (corresponding admin roles). Users navigation displays the names, roles and active state. SO salesperson is selected from active Sales users instead of free text.

Existing Admin 1 and Admin 2 responsibilities continue; no additional permissions, production authentication or privilege escalation for Admin 3 / Admin super are inferred. Their detailed permission policy remains to be specified. Data resets with the page session.
