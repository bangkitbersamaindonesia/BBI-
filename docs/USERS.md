# BBI users — session master

Seven active named user records are seeded with stable IDs: Doni, Lutfi and Dipa (Sales); admin 1, admin 2, admin 3 and admin super (corresponding admin roles). Users navigation displays the names, roles and active state. SO salesperson is selected from active Sales users instead of free text.

This creates demo master records only, not authenticated login accounts. No passwords, email addresses or credentials are invented. Current workflow role selectors remain simulations. Existing Admin 1 and Admin 2 responsibilities continue; Admin 3 can record expense checks against selected cash/bank and expense subaccounts in the demo. Production authentication and Admin super permissions remain to be specified. Data resets with the page session.
