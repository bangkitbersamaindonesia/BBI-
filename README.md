# BBI Web App

Starter project aplikasi web BBI menggunakan Vite dan JavaScript.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buka URL lokal yang ditampilkan Vite.

## Build

```bash
npm run build
npm run preview
```

## Berikutnya

Gunakan Codex untuk mendefinisikan fitur aplikasi, halaman, database, autentikasi, dan deployment sesuai kebutuhan bisnis.
